# Custom Images Directory

You can replace any demo image with your own real photo by placing image files here in this folder (`public/images/`):

1. **Your Profile Photo**: 
   - Name your photo: `profile.jpg` (or `.png`)
   - Place it inside `public/images/profile.jpg`
   - In `src/components/Hero.tsx`, change `DEFAULT_PROFILE_IMAGE` to `'/images/profile.jpg'`.

2. **Case Study Photos**:
   - `solis.jpg` (for Solis Cambodia tractor project)
   - `khb-media.jpg` (for KHB Media agency / dashboard)
   - `ecommerce.jpg` (for Riich Me / epos-godigital / KMall)
